## 🎯 Project Overview
This repository contains the core codebase for an intelligent web-based agent designed to streamline food delivery interactions. Built as an academic demonstration of web capabilities, the application structure and logic are cleanly organized into a single interactive interface.

## ✨ Key Features
* **Interactive Interface:** A user-friendly layout designed for seamless ordering and easy navigation.
* **Lightweight Architecture:** All core structure and agent logic are efficiently consolidated into a single `index.html` file.
* **Live Deployment:** Hosted directly via GitHub Pages for instant, reliable access.
